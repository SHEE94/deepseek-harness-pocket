# 移动端舒适包

为手机/平板上的 DSH Web GUI 提供触摸人体工学适配。配合《DSH on Android》部署方案
（Termux + proot 跑 `dsh --profile web`，Chrome/WebView 加载本机 GUI）使用，
也可在任何触摸设备浏览器独立生效。

## 判定规则

以**指针类型**为主判据（与视口宽度无关）：`pointer: coarse` 或 `hover: none` 时启用；
桌面（`pointer: fine` 且 `hover: hover`）整体隐藏——把桌面浏览器窗口拖窄不会看到
手机工具片，也不会吃到输入框字号下限。

## 功能

**工具片（composer 下方，触摸视口内可见）**

| 工具片 | 行为 |
|---|---|
| 侧栏 | 收起/展开左侧会话栏（官方 `layout.toggleSidebar`）。能力探测失败时置灰并把「不可用」写进可见标签 |
| 字号+ / 字号− | 按 ±2px 步进整体字号（走官方 `theme.setFontSize`）。各角色上限由宿主决定：到界如实提示并告知反向回调；无主题服务时置灰 |
| 触摸优化 | 舒适样式层开关；开启态为**填充胶囊**（不只靠 1px 描边），按下即时生效并逐浏览器记忆 |
| 说明 | 可折叠说明面板（按压态明示）。全行没有任何小于 44px 的关闭按钮 |

**舒适样式层（仅触摸判定生效内）**

- 点按高亮保留但改品牌色弱反馈（`color-mix`，老 WebView 有 `rgba` 灰档兜底），不是清成透明
- `touch-action: manipulation` 消除双击缩放延迟；`-webkit-text-size-adjust` 锁定
- 输入控件字号下限 16px（`!important`，确保压得住宿主 class 规则），阻止 iOS 聚焦整页放大
- `html, body` 的 `overscroll-behavior-y: contain`；细滚动条；横向溢出带边缘渐隐

颜色一律不覆盖：组件只引用宿主主题令牌（`--dsw-alias-*`，带 `currentColor` 兜底），
亮/暗/自定义主题自动跟随。

## 边界（如实声明）

- **两种持久化，行为不同**：「触摸优化」「说明面板」= **本浏览器本地**（localStorage，默认开启），存储被禁时明确提示「本次设置不会保留」；「字号±」= **写入宿主主题设置**，跨刷新保留、卸载插件后仍保留，恢复入口在 设置 → 外观
- 各文字角色可调范围不同：连续单方向调节可能改变角色间相对比例；到界提示由宿主真实上限触发，绝不伪造
- 键盘弹起（`visualViewport` 实测，媒体查询兜底）：说明面板退让，工具片保持一行
- 安全区内边距最多补 8px，且依赖宿主声明 `viewport-fit=cover`，未声明按 0
- 状态单向同步：localStorage 是唯一真源；工具片、样式层、其它标签页向它收敛（storage/visibility 事件驱动）
- 不修改宿主 DOM、不注册覆盖层、不替换应用根节点；组件卸载即清理样式与监听
